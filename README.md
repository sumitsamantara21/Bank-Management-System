# Bank Management System (C++)  
A console-based bank management system written in C++ for academic purposes.

## Description  
Allows basic banking operations: creating account, deposit, withdraw, display account details.

## Features  
- Create new account  
- Deposit money  
- Withdraw money  
- Display account details  
- Persistent storage using file handling  

## Build & Run  
- Requirements: C++ compiler (g++, Visual Studio)  
- Compile: `g++ main.cpp account.cpp -o BankSystem`  
- Run: `./BankSystem`  

## Usage  
Follow on-screen menu prompts to perform operations.
